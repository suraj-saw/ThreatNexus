# ThreatNexus Event & Alert Schema Specification

This document defines the unified JSON schema for incoming security events and the schema for alerts generated by the Apache Spark Structured Streaming engine.

---

## 1. Security Event Schema

All incoming security logs—whether generated synthetically, replayed from benchmark datasets (CIC-IDS2017), or ingested directly via the REST API—are normalized into the following JSON schema:

```json
{
  "event_id": "evt-7f89d3a1b2c4",
  "timestamp": "2026-11-10T10:00:05Z",
  "source": "auth-demo",
  "source_ip": "198.51.100.25",
  "destination_ip": "10.0.0.10",
  "destination_port": 22,
  "event_type": "FAILED_LOGIN",
  "username": "root",
  "status": "failure",
  "dataset_label": "synthetic:brute_force",
  "process_name": null,
  "severity": "HIGH",
  "message": "Failed SSH login attempt 1/7 from 198.51.100.25"
}
```

### Field Definitions

| Field Name | Type | Required | Description | Example Values |
| :--- | :--- | :--- | :--- | :--- |
| `event_id` | string | Yes | Unique identifier for event traceability | `"evt-3a8f12c49b01"` |
| `timestamp` | string (ISO-8601) | Yes | Event generation time in UTC | `"2026-11-10T10:00:05Z"` |
| `source` | string | Yes | Data generator or collector identity | `"threatnexus-generator"`, `"api"`, `"cic_ids2017"` |
| `source_ip` | string | Yes | Originating IPv4/IPv6 address (uses RFC 5737 demo blocks) | `"198.51.100.25"`, `"192.0.2.14"` |
| `destination_ip` | string | No | Target internal IP address | `"10.0.0.10"`, `"10.0.0.20"` |
| `destination_port` | integer | No | Target service TCP/UDP port (1-65535) | `22`, `80`, `443`, `3306` |
| `event_type` | string | Yes | Normalized event category | `"FAILED_LOGIN"`, `"NETWORK_CONNECTION"`, `"PROCESS_EXECUTION"`, `"AUTHENTICATION"` |
| `username` | string | No | Target account or actor | `"admin"`, `"root"`, `"svc_backup"` |
| `status` | string | Yes | Operational outcome of event | `"success"`, `"failure"`, `"attempted"`, `"executed"` |
| `dataset_label` | string | No | Source category indicator for dataset traceability | `"synthetic"`, `"cic_ids2017:SSH-Patator"`, `"cic_ids2017:PortScan"` |
| `process_name` | string | No | Name of binary executed (for process events) | `"mimikatz"`, `"nc.exe"`, `"nmap"` |
| `severity` | string | Yes | Initial assigned severity rating | `"INFO"`, `"MEDIUM"`, `"HIGH"`, `"CRITICAL"` |
| `message` | string | No | Human-readable log description | `"Failed SSH login attempt"` |

---

## 2. Threat Alert Schema

Generated by Apache Spark Structured Streaming detection rules and persisted to Apache HBase:

```json
{
  "alert_id": "alert-bruteforce-7c9e1a4f02b8",
  "created_at": "2026-11-10 10:00:35.123456",
  "rule_id": "BRUTE_FORCE_001",
  "source_ip": "198.51.100.25",
  "severity": "HIGH",
  "alert_type": "FAILED_LOGIN_BURST",
  "event_count": 7,
  "window_start": "2026-11-10 10:00:00",
  "window_end": "2026-11-10 10:00:60",
  "description": "Repeated failed logins detected: 7 attempts within 60s",
  "status": "open"
}
```

### Field Definitions

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `alert_id` | string | Deterministic unique alert identifier combining rule prefix and hash |
| `created_at` | string (Timestamp) | Timestamp when the alert was triggered and generated by Spark |
| `rule_id` | string | Standard detection rule code (`BRUTE_FORCE_001`, `PORT_SCAN_004`, `SUSPICIOUS_PROC_005`, `TRAFFIC_SPIKE_003`, `CIC_DATASET_ATTACK_006`) |
| `source_ip` | string | Suspect source IP address responsible for the anomalous pattern |
| `severity` | string | Triage rating (`LOW`, `MEDIUM`, `HIGH`, `CRITICAL`) |
| `alert_type` | string | Human-readable classification tag |
| `event_count` | integer | Number of qualifying events aggregated within the detection window |
| `window_start` | string | Beginning of the event-time sliding window |
| `window_end` | string | End of the event-time sliding window |
| `description` | string | Clear explanatory detail on the trigger condition |
| `status` | string | SOC investigation lifecycle stage (`open`, `investigating`, `resolved`) |
